## 🚀 Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/priyotoshdey2006-sudo/FUTURE_FS_01.git
   ```

2. Open the project:
   ```bash
   cd FUTURE_FS_01
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.
